# Meetup Management & Attendance System

## Overview

A full-stack web application for creating, managing, and attending meetups. Organizers can create events, track registrations, manage attendance, and view analytics.

## Features

### Meetup Creation

* Meetup Title
* Meetup Banner
* Description
* Date & Time
* Venue
* Google Maps Link
* Capacity Limit
* Registration Deadline

### Meetup Registration

* Why do you want to attend?
* What do you want to learn?
* What can you contribute?

### Attendance Management

* Check-In System
* Live Attendee List
* Attendance Tracking

### Networking

* User Profiles
* Connection Requests

### Analytics

* Total Registrations
* Total Check-Ins
* Attendance Percentage
* Most Active Members
* Meetup History
* CSV Export

## Tech Stack

### Frontend

* React
* Vite
* React Router
* Axios

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* Mongoose
* JWT Authentication
